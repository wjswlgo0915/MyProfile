## 01. TA 세션 HTML/CSS 웹페이지 수정 실습

**활동 구분:** 초급프로젝트 TA 세션

**진행 날짜:** 2026년 9월 17일

**진행 상태:** 실습 완료

### 활동 목적

TA 세션에서 제공된 HTML/CSS 예제 파일을 직접 수정하면서 웹페이지의 구조와 반응형 디자인의 원리를 이해하는 것을 목표로 했습니다.

### 사용 기술

- HTML: 프로필 이미지 파일 경로 수정
- CSS: 화면 요소의 배치와 스타일 이해
- Media Query: 화면 크기에 따른 반응형 웹 디자인 학습

### 담당 역할 및 수행 과정

TA 세션에서 제공된 기존 `test.html` 파일을 바탕으로 자기소개 웹페이지 수정 실습을 진행했습니다.

1. HTML 코드를 수정하여 프로필 사진을 변경했습니다.
2. CSS와 미디어 쿼리를 살펴보며 화면 크기에 따라 요소가 배치되는 방식을 실습했습니다.
3. 브라우저 창의 크기를 변경하면서 프로필과 취미 목록이 화면 너비에 따라 재배치되는 것을 확인했습니다.

기존 예제의 전체 구조를 처음부터 개발한 것이 아니라, 사진 변경과 반응형 화면 확인을 중심으로 실습했습니다.

### 실습 결과

프로필 사진을 변경하고, 브라우저 너비가 500px 이하일 때 프로필과 취미 목록이 세로로 배치되는 반응형 웹페이지의 동작을 확인했습니다.

[TA 세션 웹페이지 결과물 보기](/MyProfile/ta-session/test.html)

### 배운 점 및 개선 방향

이번 실습을 통해 HTML에서 이미지 파일을 연결하는 방법과 CSS의 미디어 쿼리를 활용한 반응형 웹 디자인의 원리를 이해할 수 있었습니다.

앞으로는 기존 코드를 수정하는 단계에서 나아가, 직접 웹페이지의 구조를 설계하고 다양한 화면 크기에 대응하는 반응형 디자인을 구현해 보고 싶습니다.
